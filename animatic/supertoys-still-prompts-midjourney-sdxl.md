# A SUMMER FOR SUPERTOYS
## Still Prompts for Animatic (Midjourney + SDXL)

Use these prompts with the panel numbers from `planning/supertoys-storyboard-panel-checklist.md`.

## Global Continuity Lock

### Character anchors
- `David`: synthetic boy, age 7, dark hair, pale skin, expressive eyes, simple cream shirt and slate shorts.
- `Henry` (bear): worn golden plush, visible stitch repairs, subtle mechanical seams, glass eyes, chest status light.
- `Monica`: elegant woman, late 20s, sculptural posture, refined neutral clothing, emotionally restrained face.
- `David`: corporate executive, mid-30s, tailored formalwear, controlled smile, tired eyes.

### Environment anchors
- Eternal holographic garden, warm amber light, roses, immaculate pathways.
- Swinton interiors: clean retro-futurist architecture, quiet luxury, subtle dystopian sterility.
- SYNTHANK hall: chrome, glass, cool cyan accents, press flashes.

### Visual style lock
- Cinematic 2.39:1 composition.
- Painterly-but-photoreal hybrid animation look.
- High emotional contrast: warm exteriors vs cool corporate interiors.
- Controlled depth of field; avoid over-busy backgrounds.

### Global negative prompt (all SDXL panels)
`lowres, blurry, watermark, text artifacts, logo, deformed hands, extra fingers, duplicate face, melted fabric, noisy skin, oversaturated neon, cartoonish proportions, anime style`

### Suggested fixed settings
- Midjourney: `--ar 21:9 --stylize 120 --chaos 8 --quality 1`
- SDXL: 1344x576 or 1536x640, CFG 5.5-7, 30-40 steps, DPM++ 2M Karras

## Batch Generation Tips
- Generate keyframes first: `P01, P07, P17, P20, P25, P28, P32`.
- Lock one seed per character-heavy sequence to keep consistency:
  - Nursery sequence: seed A
  - Corporate sequence: seed B
  - Window/dusk/night sequence: seed C
- If character drift appears:
  - Repeat character descriptors at prompt start.
  - Reduce stylization.
  - Use image-to-image from approved prior panel.
